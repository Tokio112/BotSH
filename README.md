# Утренний Telegram-бот

Каждое утро присылает сводку: погода, что надеть, расписание пар и работы (с переменами),
когда выходить из дома и с работы в колледж, планы на день и во сколько лечь спать.
В течение дня напоминает выйти, закончить работу и лечь спать.

## Запуск

1. Создай бота у @BotFather в Telegram и скопируй токен.
2. Установи Python 3.10+ и зависимости:
   `pip install -r requirements.txt`
3. Положи токен в файл `.env` (по образцу `.env.example`) или задай переменную окружения:
   - Linux/macOS: `BOT_TOKEN=... python bot.py`
   - Windows (cmd): `set BOT_TOKEN=...` и затем `python bot.py`
4. Открой бота в Telegram и нажми /start — он сам спросит город, работу/учёбу, подъём,
   время в пути и расписание. Файлы редактировать не нужно.

Чтобы сводка приходила утром, `bot.py` должен работать постоянно (твой ПК, VPS или хостинг).
Данные хранятся в `bot.db` рядом с ботом. Погода — Open-Meteo (бесплатно, без ключа).

## Формат расписания (вводится в боте)

- `пн-пт 09:00-17:00` — работа каждый будний день
- `пн 09:00-12:00` и `пн 15:00-17:00` — день разбит на два рабочих блока
- `пн 12:10-13:40 Математика` — пара; перемены считаются по промежуткам между парами
- `пн,ср 13:00-14:30 Английский`, `будни 08:30-10:00`, `сб-пн ...`

Подъём по дням: `/settings` → «Подъём», например `пн-пт 06:30` или `сб,вс 09:00`.

## Дополнительные возможности

**Приоритет при конфликте.** Если пара и работа пересекаются или не хватает времени на дорогу
(пара кончается в 13:30, работа с 13:00), бот пропускает менее важное и показывает, когда выходить.
Приоритет (работа/учёба) задаётся при настройке и меняется в «⚙️ Настройки». Если приоритет у учёбы,
рабочий блок, который конфликтует с парой, пропускается целиком — для частичной работы
разбей день на блоки (например, `пн 09:00-12:00` и `пн 15:00-17:00`).

**Сон с допуском.** Можно указать диапазон, например `7-9`. Бот советует оптимальное время (середина диапазона)
и крайний срок (минимум сна). Одно число (`8`) работает как раньше.

**Сокращённый день.** «📅 Расписание» → «✂️ Сокращённый день» → день → длительность пары:
- `60` — пары начинаются как обычно, но заканчиваются через 60 минут;
- `60 5` — пары идут подряд по 60 минут с переменами по 5 минут (большие окна между парами сохраняются).
Посмотреть и удалить такие дни: «📋 Особые дни».

**Женский календарь.** Включается в «⚙️ Настройки» → «🌸 Женский календарь». Бот спрашивает дату последних
месячных, длину цикла и длительность месячных, дальше уточняет их по твоим отметкам. Команда `/cycle`:
фаза цикла, прогноз следующих месячных и овуляции, отметки «начались/закончились», заметки о самочувствии,
история, удаление всех данных. В утренней сводке появляется блок про цикл (в том числе предупреждение
за 3 дня до месячных), а в дни менструации и ПМС бот берёт верхнюю границу диапазона сна.
Это оценка по введённым данным, не медицинская рекомендация и не метод контрацепции.

Если у тебя уже есть `bot.db` от прошлой версии, он обновится автоматически.
